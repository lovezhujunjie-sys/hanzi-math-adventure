# 汉字 · 数学 大冒险

给两个孩子做的**汉字 + 数学自学 App**：大宝曾麟轩（小学二年级）、二宝曾强（3 岁半，幼儿园小班）。
跟「[单词大冒险](https://lovezhujunjie-sys.github.io/danci-adventure-english/)」是同一套形态——**单文件网页，点开就能玩，不用装东西，没网也能玩**。

> **在线玩（GitHub Pages）**：https://lovezhujunjie-sys.github.io/hanzi-math-adventure/
> 手机上打开后「添加到主屏幕」，图标就像个 App，全屏、离线可用。

---

## 这是什么

一个纯前端的儿童学习应用，**一个 `index.html` 就是全部**（无构建步骤、无后端、无外部依赖），进度存在浏览器 `localStorage` 里，配 `sw.js` 做离线缓存。

设计定调（老曾 2026-09-18）：**「都需要是那种孩子能联想的、场景化图片化游戏化的」**——所以每个字配大图、每道数学题配实物图（小棒 / 十格阵 / 点阵 / 分堆），让孩子先看见、再理解，不是死记。

## 里面有什么

| | 🧒 麟轩（二年级） | 👶 曾强（3 岁半） |
|---|---|---|
| 数学 | **11 个关卡**（现场出题，无固定题库） | 7 个关卡 |
| 汉字 | 二年级上下册 **1100+ 个字**（按册 / 单元 / 写字表·识字表分组） | **76 个字**（每个配一张大图） |

**大宝这边**：🚀 数学闯关（100 以内加减、乘法口诀、除法、有余数除法、混合运算、比大小、列竖式、单位换算、应用题）· ⏱️ 限时口算 · 🔢 乘法口诀（点一句听一句）· 🔤 认汉字 · ✍️ 描红写字 · 🏆 星星奖章 · 👆 **点字注音**（任何地方点一下不认识的字，弹拼音气泡 + 自动念，多音字按词给音）。

**二宝这边**：数一数、比多少、认形状、找规律，全配 emoji 大图；汉字 7 个生活主题共 76 个字。

数学题都**画了图**：小棒（一捆 10 根）、点阵、盘子分堆、十格阵——孩子看着图数，不是背答案。

## 技术形态

- **单文件** `index.html`（纯前端 + `localStorage`），9 个 screen，两个 `<script>` IIFE。
- `sw.js`：Service Worker 离线缓存，stale-while-revalidate 策略（秒开 + 后台悄悄更新）。🔴 **每次改 `index.html` 都要顶 `sw.js` 里的 `VERSION`**，否则老缓存不清、孩子看到旧版。
- Web Speech API 做中文朗读（TTS），Web Audio API 实时合成音效（零音频文件）。
- Canvas 描红、SVG 数学教具（小棒 / 十格阵 / 点阵）。
- 拼音点读系统：1651 个字的默认读音 + 219 条词语读音，多音字按词定音。

## 视觉设计

糖果色儿童向 UI：珊瑚橙渐变主按钮（`#FF7A59 → #FFB03A`）、淡蓝天空光晕背景（`#F3F7FF`）、果冻卡片、漂浮 / 摇摆 / 弹跳动画。答对 = 绿色 pop，答错 = 红色 shake（「错 = 红」是孩子的通用信号）。

## 本地跑

```bash
# 直接双击 index.html 就能玩；或起个本地服务器（Service Worker 需要 http 环境）
python3 -m http.server 8765
# 打开 http://localhost:8765/index.html
```

## 诚实边界（这些得说清楚）

- ⚠️ **还没有任何真人（孩子）用过**。所有检查都是电脑自动跑的，「难不难」「坐不坐得住」只有孩子试了才知道。
- ⚠️ 二年级的字大部分**没有配图**——这些字（如「依」「尽」「穷」）本来没法用一张图表示，硬配图反而教错联想，所以改成给**组词**（词就是它的场景）。
- ⚠️ **按钮上的字点不出拼音**（故意的）：认字闯关的选项、组词卡按一下有自己的功能，且点一下就出拼音等于直接给答案。
- ⚠️ 写字只判「有没有写」，**不判笔顺、不判像不像**。
- ⚠️ 拼音是按词一条条定的，不是课本印刷那版；变调 / 轻声一律给本调（跟课本给单字注音一致）。
- ⚠️ 读音用浏览器自带 TTS，**音色跟着设备走**。
